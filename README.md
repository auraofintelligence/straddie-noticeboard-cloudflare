# Straddie Noticeboard Network

A local community resource and a proposal for permanent noticeboard infrastructure on Minjerribah / North Stradbroke Island. The funding case covers island-wide installation, year-round editorial and technical operations, maintenance and asset renewal. The December–January school holidays are a possible opening season. The public board is an everyday use of a wider network designed for self-sovereignty. The independent A$6 million pitch would establish a frontier-class compute node in Dunwich for uses including digital twins of councils, electorates and bioregions. The longer-term ambition is to develop volunteer and tourism operations architecture on Straddie for Brisbane 2032. Luke Nathan Hayes is developing the proposal through [Strange But True](https://auraofintelligence.github.io/strange-but-true/index.html) while seeking local support to form Ready SETCO. The proposed co-operative would convene local publishers and hosts and moderate the board. The software includes a reviewed public feed. Participating sites, an accountable asset owner, service agreements and funding still need local agreement.

## Run locally

With Python 3 and Node.js available, run `npm start` from this folder and open [localhost:4185](http://localhost:4185/). Run `npm run check` to check the JavaScript modules. The site has no install step or hosted service dependencies.

- The homepage introduces the island network proposal, community resources and a worked Dunwich notice. The [publishing guide](public/how-it-works.html) explains the workflow and responsibilities. The [practice noticeboard](public/board.html) filters examples by place and category. [Project references](public/network.html) stay in the home footer.
- The [media training page](public/training.html) takes a beginner from a story brief and source check through phone recording, editing, captioning, publication and corrections.
- The [setup guide](public/setup.html) covers TV players, independent power, reviewing notices, Council coordination, outage exercises and commissioning participating sites. [Screens and outages](public/resilience.html) explains failure modes and correction checks.
- [Business onboarding](public/businesses.html) covers posting and hosting, with a local plan exporter. [Infrastructure funding](public/grants.html) covers capital costs, recurring service, renewal, evidence and funding enquiries.
- The [draft editor](public/submit.html) keeps the active draft in this browser. Authors choose the public outlets they want (web, venue TV or touch kiosk). The review copy and optional AI writing prompt include those choices. The author shares the draft with the responsible reviewer and checks any adaptations.
- The screen preview can rotate the sample notices or show them one at a time. The portrait preview offers touch controls and a link to the matching town map. Use `screen.html?place=Dunwich&format=portrait&outage=1` to try text fallback with the sample set.
- The [island travel guide](public/island.html#transport) links to ferries, bus routes 880 and 881, terminal stop departures, weather and Council's disaster dashboard. The [future transport section](public/island.html#future-mobility) links to the Moreton Bay proposal, Tesla roadshow and Gold Coast air taxi agreement. A new browser session needs connectivity to load the site. Installed offline packs, battery runtime and restoration procedures need verification at each installation.

- The [island infrastructure plan](public/pilot.html#sovereignty) explains contributor control and the proposed independently operated nodes described in the Sensorium paper. [Visitor and volunteer operations](public/visitor-volunteer.html#handover) lets readers follow a corrected workshop notice from the organiser to an offline screen. [Work and volunteering](public/opportunities.html) includes sourced opportunity finders and a private Community Hours worksheet. [Emergency information](public/emergencies.html) points residents and visitors to the issuing agencies and local radio.

## Publishing a pilot notice

The [pilot board](http://localhost:4185/board.html?mode=pilot) and [pilot screen](http://localhost:4185/screen.html?mode=pilot) use the reviewed notices in [pilot-notices.json](public/data/pilot-notices.json). The initial feed is empty. Example notices are available in the practice board.

1. An author exports a local draft and shares it with the responsible reviewer. Confirm the issuer, reuse permissions, approved outlets and closing time. The entire feed is publicly readable. Keep private contacts, rosters and permission records outside the public folder.
2. An authorised steward adds an approved record to the file’s `notices` array. Leave the top-level `schema` as `notice-feed.v1` and `zone` as `minjerribah`. Each record requires a unique lower-case, hyphenated `id`, `status` set to `approved`, `title`, `publisher`, `place`, `category`, `summary`, public HTTPS `sourceUrl`, a public `reviewedBy` role or credit, `reviewedAt` and `expiresAt`. Use the places and categories in the draft form. Timestamps include seconds and an offset, for example `2027-02-15T09:00:00+10:00`. An optional `startsAt` controls when display begins.
3. Copy the author's approved choices into `outlets`. Use a nonempty array of distinct values from `web` (mobile and web board), `tv` (venue, onboard or read-only stop display) and `kiosk` (public touchscreen). For example, `"outlets": ["web", "kiosk"]` allows the board and touchscreen to display the notice. Older approved records with no `outlets` field display on all three. New drafts start with web selected.
4. Run `npm run check:feed`. Review the change on the local pilot board, TV and portrait screen. Release the same checked site to the participating hosts under the agreed publication process. Connected devices request updates roughly once a minute and remove expired notices at their take-down time.
5. Correct or renew a notice under its existing ID with a fresh review time. Preserve its outlet list unless the publisher has approved a change. For a withdrawal, remove the row or replace it with only its ID and `"status": "withdrawn"`. Publish the revision and have the affected hosts verify it on their displays. If the feed cannot be checked, the pilot display reports it as unavailable.

## Cloudflare

The `public/` folder is the complete deployable site. `wrangler.jsonc` configures Cloudflare Workers Static Assets. When ready to publish from an authenticated Cloudflare session, run `npx wrangler deploy` in the repository root. The local pilot has no deployed Cloudflare URL.
