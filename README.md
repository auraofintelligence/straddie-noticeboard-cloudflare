# Straddie Noticeboard Network

A local community resource and a proposal for permanent noticeboard infrastructure on Minjerribah / North Stradbroke Island. The funding case covers island-wide installation, year-round editorial and technical operations, maintenance and asset renewal. The December–January school holidays are a possible opening season. The public board is an everyday use of a wider network designed for self-sovereignty. The independent A$6 million pitch would establish a frontier-class compute node in Dunwich for uses including digital twins of councils, electorates and bioregions. The longer-term ambition is to develop volunteer and tourism operations architecture on Straddie for Brisbane 2032.

Luke Nathan Hayes holds the preparatory work and prototype through his business, Strange But True. The noticeboard is intended to be the first project of Ready SETCO, a proposed co-operative that depends on local people choosing to form and support it. If formed, its members would decide whether and how to take on the service through an agreed handover. Participating sites, asset ownership, service agreements and funding still need local agreement. The prototype includes a reviewed public feed. [Strange But True](https://auraofintelligence.github.io/strange-but-true/index.html) · [Ready SETCO’s first project proposal](https://ready-setco.auraofintelligence.workers.dev/media-assets.html#noticeboard-first)

## Run locally

With Python 3 and Node.js available, run `npm start` from this folder and open [localhost:4185](http://localhost:4185/). Run `npm run check` to check the JavaScript modules. The site has no install step or hosted service dependencies.

## Publishing a pilot notice

The [pilot board](http://localhost:4185/board.html?mode=pilot) and [pilot screen](http://localhost:4185/screen.html?mode=pilot) use the reviewed notices in [pilot-notices.json](public/data/pilot-notices.json). The initial feed is empty. Example notices are available in the practice board.

1. An author exports a local draft and shares it with the responsible reviewer. Confirm the issuer, reuse permissions, approved outlets and closing time. The entire feed is publicly readable. Keep private contacts, rosters and permission records outside the public folder.
2. An authorised steward adds an approved record to the file’s `notices` array. Leave the top-level `schema` as `notice-feed.v1` and `zone` as `minjerribah`. Each record requires a unique lower-case, hyphenated `id`, `status` set to `approved`, `title`, `publisher`, `place`, `category`, `summary`, public HTTPS `sourceUrl`, a public `reviewedBy` role or credit, `reviewedAt` and `expiresAt`. Use the places and categories in the draft form. Timestamps include seconds and an offset, for example `2027-02-15T09:00:00+10:00`. An optional `startsAt` controls when display begins.
3. Copy the author's approved choices into `outlets`. Use a nonempty array of distinct values from `web` (mobile and web board), `tv` (venue, onboard or read-only stop display) and `kiosk` (public touchscreen). For example, `"outlets": ["web", "kiosk"]` allows the board and touchscreen to display the notice. Older approved records with no `outlets` field display on all three. New drafts start with web selected.
4. Run `npm run check:feed`. Review the change on the local pilot board, TV and portrait screen. Release the same checked site to the participating hosts under the agreed publication process. Connected devices request updates roughly once a minute and remove expired notices at their take-down time.
5. Correct or renew a notice under its existing ID with a fresh review time. Preserve its outlet list unless the publisher has approved a change. For a withdrawal, remove the row or replace it with only its ID and `"status": "withdrawn"`. Publish the revision and have the affected hosts verify it on their displays. If the feed cannot be checked, the pilot display reports it as unavailable.

## Cloudflare

The [public Straddie Noticeboard Network site](https://straddie-noticeboard-cloudflare.auraofintelligence.workers.dev/) runs on Cloudflare Workers Static Assets. The [reviewed noticeboard](https://straddie-noticeboard-cloudflare.auraofintelligence.workers.dev/board.html?mode=pilot) reads the published feed. The [practice board](https://straddie-noticeboard-cloudflare.auraofintelligence.workers.dev/board.html) carries example notices.

To publish an update, run `npm run check`, then `npx wrangler deploy` from the repository root while signed in to the Cloudflare account. `wrangler.jsonc` selects the Worker and the `public/` directory. `public/.assetsignore` keeps the two retired aerial images out of the upload.
